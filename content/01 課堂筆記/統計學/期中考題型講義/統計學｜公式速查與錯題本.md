## 二、公式與適用條件

### 機率

$$P(A^c)=1-P(A),\quad P(A\mid B)=\frac{P(A\cap B)}{P(B)}\quad(P(B)>0).$$

$$P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B\mid A)P(A)+P(B\mid A^c)P(A^c)}.$$

若兩事件獨立，才有 $P(A\cap B)=P(A)P(B)$。使用乘法前，先確認題目是否給定獨立，或說明採用獨立假設。

### 期望、變異數與標準差

| 題目形式  | 正確公式                                                |     |                       |
| ----- | --------------------------------------------------- | --- | --------------------- |
| 離散分配  | $E[h(X)]=\sum_x h(x)p(x)$                           |     |                       |
| 連續密度  | $E[h(X)]=\int h(x)f(x)dx$                           |     |                       |
| 變異數   | $\operatorname{Var}(X)=E(X^2)-[E(X)]^2$             |     |                       |
| 加減乘常數 | $E(a+bX)=a+bE(X)$                                   |     |                       |
| 變異數轉換 | $\operatorname{Var}(a+bX)=b^2\operatorname{Var}(X)$ |     |                       |
| 標準差轉換 | $\operatorname{SD}(a+bX)=                           | b   | \operatorname{SD}(X)$ |

### 密度與轉換

$$f\ge0,\quad\int f=1,\quad F_Y(y)=P(h(X)\le y).$$

先求新變數範圍，再將事件改寫成舊變數的區間，最後微分。在非單調轉換如平方時，正負兩個來源都要算。

### 才比雪夫

$$P(|X-\mu|<a)\ge\max\left\{0,1-\frac{\sigma^2}{a^2}\right\},\quad a>0.$$

只需有限變異數，不必假設常態；若區間偏離 $\mu$，先找出可套用公式的對稱範圍，再計算端點到平均的距離。

### 聯合與條件期望

$$f_X(x)=\int f_{X,Y}(x,y)dy,\quad f_{X\mid Y}(x\mid y)=\frac{f_{X,Y}(x,y)}{f_Y(y)}.$$

$$E[E(X\mid Y)]=E(X).$$

沿用手寫中的完整條件期望記號：

$$E[(X-\varphi(Y))^2]=E[(X-E(X\mid Y))^2]+E[(E(X\mid Y)-\varphi(Y))^2].$$

比值要邊際密度為正；疊代期望需可積分；平方誤差分解在相關二階動差有限時使用。
