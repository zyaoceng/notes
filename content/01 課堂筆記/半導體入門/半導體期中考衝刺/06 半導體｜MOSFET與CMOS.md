# 06｜MOSFET、CMOS 與傳輸閘

[[00 半導體期中考｜今晚從這裡開始|回首頁]] · 前章 [[05 半導體｜pn接面與二極體]] · 下一章 [[07 半導體｜考前自測與解題模板]]

## 一、★ MOSFET：用電壓控制通道

MOSFET＝Metal–Oxide–Semiconductor Field-Effect Transistor，**金屬氧化物半導體場效電晶體**。本課可以先想成「用閘極電壓調節源極與汲極之間的導電通道」。

| 名詞 | 意思 |
|---|---|
| G，Gate，閘極 | 控制端；透過氧化層的電場影響通道 |
| S，Source，源極 | 載子來源端，也是 $V_{GS}$ 的參考端 |
| D，Drain，汲極 | 載子流經通道的另一端 |
| B，Body／Bulk，基體 | 半導體基板；本課基本題通常用固定接法 |
| 氧化層 oxide | 閘極與半導體之間的絕緣層，常以 SiO₂ 示意 |
| 通道 channel | S 與 D 間可讓載子移動的區域 |
| $V_{GS}=V_G-V_S$ | 閘源電壓，單位 V；**不是閘極對地電壓** |
| $V_{DS}=V_D-V_S$ | 汲源電壓，單位 V |
| $V_{th}$ | 臨界／閾值電壓，單位 V；理想模型通道開關的分界 |
| $I_D$ | 汲極電流，單位 A |

理想氧化層不讓直流穿過，所以閘極輸入阻抗很高；但閘極有電容，切換時仍要充放電。**閘極不需持續大直流，並不等於切換不用能量。**

NMOS 通道主要載子是電子；PMOS 通道主要載子是電洞。**n/p 通道種類**與**增強/空乏操作模式**是兩個不同分類。

## 二、★ 四種 MOS 一張表記完

**增強型 enhancement：原本沒有導電通道，$V_{GS}=0$ 預設關。**

**空乏型 depletion：製造時已有通道，$V_{GS}=0$ 預設開；用適當電壓耗盡通道而關閉。**

下表全部用 $V_{GS}=V_G-V_S$ 的符號慣例；忽略次臨界漏電，且說「導通」時假設有適當非零汲源電壓。

| 種類 | $V_{th}$ 正負 | $V_{GS}=0$ | 理想導通條件 | 理想截止條件 |
|---|---|---|---|---|
| 增強型 NMOS | **正** | 關 | $V_{GS}>V_{th}$ | $V_{GS}\le V_{th}$ |
| 空乏型 NMOS | **負** | 開 | $V_{GS}>V_{th}$ | $V_{GS}\le V_{th}$ |
| 增強型 PMOS | **負** | 關 | $V_{GS}<V_{th}$ | $V_{GS}\ge V_{th}$ |
| 空乏型 PMOS | **正** | 開 | $V_{GS}<V_{th}$ | $V_{GS}\ge V_{th}$ |

**記法：n 型往更正開得更強；p 型往更負開得更強。增強型零伏關、空乏型零伏開。** 先用這兩句重建表格，比只背閾值正負可靠。

- 空乏 NMOS，若 $V_{th}=-2V$：$V_{GS}=0$ 時 0＞−2，已開；−3 V 才能關；＋3 V 會更強。
- 空乏 PMOS，若 $V_{th}=+2V$：0＜2，已開；＋3 V 可關；−3 V 更強。
- 若某 PMOS 的 S 在 5 V、G 在 0 V，$V_{GS}=-5V$；不能把 G＝0 V 當 $V_{GS}=0$。

> [!note] 老師筆記 W07，第 4、5 頁
> p 空乏型：正閘源電壓排斥電洞，達正閾值時關閉。n 空乏型：負閘源電壓排斥電子，降至負閾值時關閉。

> **pn 空乏區**：接面附近自由載子很少的區域。**空乏型 MOSFET**：零閘源電壓就已有通道、預設導通的元件類型。不能看到「空乏型」就猜零電壓不導通。

## 三、★ 截止、線性與飽和不是同一回事

以一般長通道 NMOS、$V_{DS}\ge0$ 的簡化模型為例：

| 操作區 | 條件 | 白話 |
|---|---|---|
| 截止 cutoff | $V_{GS}\le V_{th}$ | 理想上 $I_D\approx0$ |
| 線性／三極區 | $V_{GS}>V_{th}$ 且 $0\le V_{DS}<V_{GS}-V_{th}$ | 像由閘壓控制的電阻 |
| 飽和 saturation | $V_{GS}>V_{th}$ 且 $V_{DS}\ge V_{GS}-V_{th}$ | 理想上 ID 對 VDS 較不敏感，主要受閘壓控制 |

**夾止 pinch-off 不等於截止 cutoff。** 飽和時汲極端通道出現夾止，但載子仍被電場帶過，仍有電流。只有閘源條件不足才是截止。

### 補充：幾倍題可能用到

$$I_D\approx\frac12\mu_n C_{ox}\frac WL(V_{GS}-V_{th})^2$$

這是長通道、飽和區、忽略通道長度調變等效應的近似。$C_{ox}$ 為**每單位面積**氧化層電容（F/m²），不是整顆電容；W 是通道寬、L 是通道長，同單位，因此 W/L 無單位。此處 W 不是功率單位，也不是 pn 空乏寬度。

定義**過驅電壓** $V_{ov}=V_{GS}-V_{th}$。其餘條件固定且仍在飽和：W ×2 → ID ×2；L ×2 → ID ×1/2；$V_{ov}$ ×2 → ID ×4。**VGS ×2 不一定讓 ID ×4，因為還要減 Vth。**

## 四、★ CMOS 反相器：輸入高，輸出低

CMOS＝Complementary MOS，**互補式 MOS**。標準反相器通常用增強型 PMOS 在上方接電源 VDD，增強型 NMOS 在下方接地；兩個閘極接同輸入，汲極相接為輸出。

| 輸入 | 上方 PMOS | 下方 NMOS | 輸出 | 理想穩態 VDD 到地直流路徑 |
|---|---|---|---|---|
| 0／低，約 0 V | 開 | 關 | 1／高，約 VDD | 被 NMOS 切斷 |
| 1／高，約 VDD | 關 | 開 | 0／低，約 0 V | 被 PMOS 切斷 |

**反相器 inverter**：輸出邏輯與輸入相反。**邏輯 0、1**代表低、高電壓範圍，不是一定 0 V、1 V。

**靜態功耗幾乎為零的核心：一開一關，電源到地沒有完整直流通路。** 不是兩個都飽和、不是輸入阻抗為零，也不是電容讓能量完全消失。

> [!note] 老師筆記 W07，第 9 頁
> 先沿著 VDD → PMOS → 輸出 → NMOS → 地追線，再找哪顆被關閉。

![[半導體-W07-p09.png|750]]

實際元件有漏電，切換時還有負載電容充放電及可能短暫直通電流。**理想靜態低功耗 ≠ 所有時候零功耗。** 補充的動態功率近似 $P_{dyn}=\alpha C_LV_{DD}^2f$；$C_L$ 負載電容（F），f 切換時脈（Hz），α 為每週期 0→1 充電事件的平均比例。其他固定，VDD 倍增，動態功率約 4 倍。

### 為什麼 PMOS 通常做比較寬？

Si 中通常 $\mu_p<\mu_n$：電洞比電子不容易漂移。驅動能力約與 $\mu W/L$ 成正比；若其他製程、過驅條件相近，為讓拉高／拉低速度接近：

$$\mu_p\frac{W_p}{L_p}\approx\mu_n\frac{W_n}{L_n}$$

同 L 時 $W_p/W_n\approx\mu_n/\mu_p$。例如題目給 μn 是 μp 的 2 倍，PMOS 寬度約設 2 倍。**不能不看條件就背永遠 2 倍。**

## 五、★ CMOS 傳輸閘：完整傳 0，也完整傳 1

**傳輸閘 transmission gate**是用 NMOS 與 PMOS **並聯**成訊號開關；控制端互補。啟用時 NMOS 的 gate 高、PMOS 的 gate 低，兩顆一起開。

| 開關 | 入門結論 | 原因摘要 |
|---|---|---|
| 單顆 NMOS | 強 0、弱 1 | 傳高電位時 VGS 逐漸減小，高電位可能受閾值限制 |
| 單顆 PMOS | 強 1、弱 0 | 擅長拉到高電位，但傳低電位可能受閾值限制 |
| CMOS 傳輸閘 | **強 0、強 1** | 兩顆互補補足 |

「強」指接近完整邏輯電位，不是指一定有巨大電流。傳輸閘不會消除所有動態功耗，也不代表實際漏電精確為零。

**分清接法：反相器上下串接、一開一關；傳輸閘訊號路徑並聯，啟用時兩顆同開。**

## 六、W07 原題逐題解析

### W07-01｜開路、熱平衡 pn 接面，哪個敘述錯誤？

**答案：『空乏區兩側淨電荷密度必定對稱且寬度相等』錯。**

**流程：** 圈「錯誤／必定」→ $N_AW_p=N_DW_n$ → 除非 NA＝ND，否則不等寬。其餘「自由載子少」「內部 E 非零」「固定溫度下摻雜增大使內建電位增加」符合本題模型。

### W07-02｜空乏型 p-MOSFET 的 Vtp 與截止方式？

**答案：$V_{tp}>0$，施正 $V_{GS}$，使 $V_{GS}\ge V_{tp}$ 可截止。**

**流程：** 空乏型 → 0 V 已開 → PMOS 需要往正方向耗盡電洞 → 正閾值。不要套增強型 PMOS 的負閾值。

### W07-03｜理想 CMOS 反相器穩態靜態電流近零的原因？

**答案：NMOS、PMOS 總有一個截止。**

**流程：** 畫電源到地 → 穩定輸入 0 或 1 → 找到串聯路徑上關閉的一顆 → 無完整直流路徑。

### W07-04｜CMOS 傳輸閘比單顆 NMOS 的最大優點？

**答案：同時完整傳遞強 0 與強 1。**

**流程：** NMOS 強 0、PMOS 強 1 → 並聯互補 → 完整電位範圍。多用一顆元件不是必然更省面積；也不會徹底消除動態功耗或所有漏電。

### W07-05｜熱平衡零偏 pn 接面，哪個內部敘述正確？

**答案：內建電場由 n 側指向 p 側。**

**流程：** n 側 D⁺、p 側 A⁻ → E 從正到負。各種載子的擴散電流與漂移電流相反，熱平衡不代表濃度梯度為零。

### W07-06｜單邊接面 NA 遠大於 ND，提高 n 側 ND，零偏時 W、Vbi？

**答案：空乏區總寬度減小，內建電位增加。**

**流程：** $V_{bi}=V_T\ln(N_AN_D/n_i^2)$ → Vbi↑；$W\approx\sqrt{2\varepsilon_sV_{bi}/(eN_D)}$ → ND 增加的效應主導，W↓。不能只因 Vbi↑ 就猜 W↑。

### W07-07｜空乏型 n-MOSFET 哪個敘述錯誤？

**答案：『欲完全截止，必須施高於閾值的正閘源電壓』錯。** 正 VGS 使電子通道更強。

**流程：** 空乏 n → Vth＜0 → 0 V 已開 → 必須降到 $V_{GS}\le V_{th}$ 才關。其餘「零閘源電壓、有汲源電壓時可導電」「正閘源電壓增加電子」「閾值負」皆正確。

### W07-08｜標準 CMOS 反相器理想上無靜態直流功耗的原因？

**答案：電源到地之間至少串聯一個截止電晶體。** 與第 3 題相同觀念、不同敘述。

**流程：** 一開一關 → 靜態直流電流近零 → $P=VDD\cdot I$ 近零。

### W07-09｜空乏型 n-MOSFET 結構與特性，哪個錯誤？

**答案：『要關閉，必須施高於閾值的正閘源電壓』錯。** 與第 7 題重複。

**流程：** 製造時預先有 n 通道 → 0 V 導通且負閾值 → 負閘壓耗盡電子。先天有通道不表示永遠關不了。

### W07-10｜對稱切換延遲時 PMOS 做較寬，物理原因？

**答案：電洞遷移率低於電子遷移率。** 用增加 W/L 補償較小 μ。

**流程：** 比驅動能力 $\mu W/L$ → μp 較小 → Wp 要較大。不是 PMOS 承受電源必定比較高，也不是氧化層電容天生一定較小。

## 七、解題流程

**MOS 題：先看 n/p → 再看增強/空乏 → 算 VGS＝VG−VS → 與有正負號的 Vth 比較。**

**CMOS 題：先分反相器／傳輸閘 → 判哪顆開關 → 追電源或訊號路徑。**
