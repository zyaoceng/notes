# Basic model

> 上層：[[首頁]]｜來源：Apple 備忘錄「醫療產業分析」資料夾

-Target Population

在醫療試驗的時候要「切分市場」 FDA會要求 回去看第三期FDA的規範

-disease 流量和存量

![[備忘錄 Basic model 1.png]]

人口＊盛行率＊確診率＊治療率＊藥價 market size

在這裡先忽略是否可負擔（有保險 且 不治療容易死）

一般疾病存量估對比流量比較重要（傳染病相反）

醫療infra沒有ready有tam也吃不到

Ex 讓病人從10年多活到12年差異不大

但讓100家醫院能做到5000家有巨大差異

很多醫療公司不是在解決藥的效用 而是解決實行到醫院的難度

做長效藥：上限不高（競爭別人定義好的市場）風險低（不用自行驗證機制的可行性 差距可到10倍）

長效藥可以為短效藥*天數＋premium

-nccn 臨床指南（癌症臨床指引） 會有「大佬名字」對公司來說 他們是必須說服的人

治療指南：競爭品跟樹狀圖會有很多資訊 用於推算tam與競爭格局

後線到前線：動態的進攻 越往前tam越大

越往前要丟出去的capex更高 前線的研發失敗可能會連帶影響後線銷售狀況

每次做trail都是給外部人重新檢視自己的機會

後續檢測也有可能輸一開始的（會讓外部懷疑是否只是僥倖）

新增市場vs現有患者

不用考量現有市場 不治療原因在於負擔不起、已經用別的藥 所以能夠貢獻的微乎其微

可以去說服醫生在「抗藥性」出現後採用或是說服醫生「我的藥比現有的要更適合在ta」

Off label use

批准在A 應用在B

Ex：排卵藥被用在男性不孕症

藥廠不能去promote這種東西 違法 但他們會委婉地推銷

大部分要自費 跟公費有概念差異

出事醫生要負責

100個新藥會有大概2-5個成功 每一個時間點都有一個機率可以算 也都大概對應一個capex因此可以算期望值

差異在於在臨床試驗的任一階段可以收手 輸可以不用輸到底

怎麼知道機率是多少？取決於你是新開發者還是後進者

可以用教授發表的paper抓detail給的概率分佈 動物實驗的數據去推估一下後來完全創新的機制成功的機率（主觀）

What if 情境分析

也可以用現價推算隱含機率 用作與自己給的機率去推估

rNPV risk 調整只需要做一次 不要計入多次 如果分子已經計入一次 就不要在discount rate 乘入一個機率

資產減損的地方會告訴你公司使用的discount rate

公司如果有給情境分析是最好 有給discount rate 、成功機率等等，可以反推公司認為的market size

-定價會給一個高價

後面做折價的時候可以容易被保險納入

因為藥廠賣進去的時候會有30-40%的利潤率 銷售就有很多空間可以發揮 比方說給一些委婉回扣給採用醫生

因為採用的跟使用的是不同人 因此把醫生那關打通非常重要 留有一個可以把利潤分出去的空間就連帶相當重要

-要融入子產業的特性

滲透率多高？滲透率成長速度多快？是否是寡占？
