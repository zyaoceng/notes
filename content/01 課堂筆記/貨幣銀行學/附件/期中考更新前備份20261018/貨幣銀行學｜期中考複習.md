# 第 1 章：貨幣是什麼、怎麼算（Ch1–3）

> [!tip] 這章最重要的一句話 **M1 = 現金 + 支票存款（能立刻拿去付錢的錢）；M2 = M1 + 儲蓄存款 + 小額定存 + 零售貨幣市場基金。公債兩個都不算。**

## 這章要搞懂什麼？

- **金融體系 (financial system)** 就是把錢從「有多餘錢的人」（儲蓄者）送到「需要錢的人」（借款者）。
- 兩條路：**直接金融 (direct finance)**＝借款者直接在市場發債券、股票賣給儲蓄者；**間接金融 (indirect finance)**＝錢先存進銀行等**金融中介機構 (financial intermediaries)**，再由銀行借出去。
- 老師的整門課地圖：Ch4–7 講直接金融（債券、股票價格），Ch8–13 講間接金融（銀行）。

## 「貨幣」的定義

- 經濟學的**貨幣 (money)** 不是「財富」也不是「所得」，而是「大家願意拿來付款的東西」。
- 貨幣三功能：**交易媒介 (medium of exchange)**、**計價單位 (unit of account)**、**價值儲藏 (store of value)**。
- **貨幣總計數 (monetary aggregates)**：依「多容易拿來付錢」（流動性）分層計算。

|層級|包含什麼|白話|
|---|---|---|
|M1|流通中的通貨 + 活期／支票存款|馬上能刷、能付|
|M2|M1 + 儲蓄存款 + 小額定期存款 + 零售貨幣市場基金|要多一步才能付，但很快|
|都不算|公債、股票|要先賣掉、價格會變|

## 完整計算（練習題 Q3）

已知：通貨 300、活期存款 500、儲蓄存款 900、小額定存 400、零售貨幣基金 250、家計持有公債 700。

- M1 = 通貨 + 活期存款 = 300 + 500 = **800**
- M2 = M1 + 儲蓄 + 小額定存 + 零售貨幣基金 = 800 + 900 + 400 + 250 = **2,350**
- 公債 700：**兩個都不算**。

## 會怎麼考、陷阱在哪？

- **陷阱 1：M2 要包含 M1。** 很多人只加後面三項得到 1,550。
- **陷阱 2：大額定存、機構型貨幣基金不在 M2**（題目若寫 large-denomination 就排除）。
- **陷阱 3：公債、股票、信用卡額度都不是貨幣。**

## 本章練習

1. 通貨 200、活期存款 350、儲蓄存款 600、小額定存 300、零售貨幣基金 150、大額定存 400、股票 900。求 M1、M2。 550 550+300+150+600=1600
2. 有人把 100 元從活期存款移到儲蓄存款，M1、M2 各怎麼變？ 450 1000

> [!note]- 答案
> 
> 1. M1 = 200 + 350 = 550；M2 = 550 + 600 + 300 + 150 = 1,600。大額定存、股票不算。
> 2. M1 減 100；M2 不變（錢只是在 M2 內部移動）。

# 第 2 章：風險、統計與金融危機（Week 1）

> [!tip] 這章最重要的一句話 **分散投資能降風險，前提是資產「不會一起出事」。2008 年危機就是因為大家假設房貸違約彼此獨立，結果一起違約；而報酬有肥尾，常態分配會低估大虧損。**

## 這章要搞懂什麼？

- **期望值 (expected value, E)**：每種結果 × 機率，加總。白話：平均會拿到多少。
- **變異數 (variance, var)**：結果離平均有多遠的平方的平均。白話：有多不確定＝風險。
    - 公式：$\text{var}(X) = E[X^2] - (E[X])^2$
- **共變異數 (covariance, cov)**：兩個東西是否同方向變動。正＝一起漲跌；負＝一個好另一個壞。
    - 公式：$\text{cov}(X,Y) = E[XY] - E[X]E[Y]$
- **投資組合變異數**：$\text{var}(aX+bY) = a^2\text{var}(X) + b^2\text{var}(Y) + 2ab,\text{cov}(X,Y)$
- **風險分攤 (risk pooling)**：把很多獨立風險放一起，平均後風險變小。**但若不獨立（cov > 0），效果大打折扣。**

## 2008 危機的邏輯

- 次級房貸 (subprime mortgages) 被打包成 MBS、CDO，切成分券 (tranches)，最高層評 AAA。
- AAA 的理由：「一筆房貸有風險，幾千筆一起就安全，因為違約是獨立的。」
- 2007 年全美房價一起跌 → 違約一起來 → 獨立性假設崩潰 → AAA 不安全。S&P 500 從 1,565 跌到 677（−56.8%）。

## 肥尾（練習題 Q2）

- **肥尾 (fat tails)**：極端結果出現的機率，遠高於同平均、同變異數的常態分配所預測的。
- 為什麼銀行資本會不夠？**資本 (capital) 的功能就是吸收大虧損；用常態分配算，大虧損機率被低估 → 準備的資本太少。**

## 隨機漫步（Random walk）

- **隨機漫步**：明天價格 = 今天價格 + 無法預測的衝擊。$P_{t+1} = P_t + \varepsilon_{t+1}$
- **AR(1)**：$P_{t+1} = \mu + \rho(P_t - \mu) + \varepsilon$。若 ρ 遠小於 1，價格會「拉回平均」→ 可預測 → 可套利。這個連到 Ch7 的效率市場。

## 完整計算（練習題 Q22：兩張債券）

Freddie、Mookie 各發一張債：還錢付 100，跑路付 0。聯合機率：

||Mookie 還|Mookie 跑|
|---|---|---|
|Freddie 還|0.2|0.3|
|Freddie 跑|0.4|0.1|

**步驟 1：各自還錢機率（邊際機率，橫加或直加）**

- Freddie 還 = 0.2 + 0.3 = 0.5；Mookie 還 = 0.2 + 0.4 = 0.6

**步驟 2：期望值與變異數**

- $E[F] = 0.5 × 100 = 50$；$E[F^2] = 0.5 × 100^2 = 5{,}000$；$\text{var}(F) = 5{,}000 - 50^2 = 2{,}500$
- $E[M] = 0.6 × 100 = 60$；$E[M^2] = 6{,}000$；$\text{var}(M) = 6{,}000 - 3{,}600 = 2{,}400$

**步驟 3：共變異數**

- $F × M$ 只有「兩人都還」時 = 100 × 100 = 10,000，其他都是 0
- $E[FM] = 0.2 × 10{,}000 = 2{,}000$
- $\text{cov} = 2{,}000 - 50 × 60 = -1{,}000$（負：一個還、另一個傾向跑）

**步驟 4：各買一半**

- $E = 0.5(50) + 0.5(60) = 55$
- $\text{var} = 0.25(2{,}500) + 0.25(2{,}400) + 2(0.5)(0.5)(-1{,}000) = 625 + 600 - 500 = 725$
- **結論：725 遠小於 2,500、2,400，負相關讓組合風險大降。**

## 會怎麼考、陷阱在哪？

- **陷阱 1：E[FM] 只算「兩個都還」那格**，不要把 0.3、0.4 也乘進去。
- **陷阱 2：組合變異數的係數是 a²（0.25），共變異數項是 2ab（=0.5）**，不是 0.5 × var。
- **陷阱 3：邊際機率要對方向加**：Freddie 看「列」，Mookie 看「欄」。
- 簡答常考：為何常態假設讓資本不足（肥尾）、為何分散投資在危機時失效（相關性上升）。

## 本章練習（同一個案例改數字）

1. 把表格改成：都還 0.5、F還M跑 0.1、F跑M還 0.1、都跑 0.3。求 cov 與各一半組合的變異數。
2. 比較第 1 題與原題，哪個組合比較安全？為什麼？

> [!note]- 答案
> 
> 1. P(F還)=0.6、P(M還)=0.6；E[F]=E[M]=60；var 各 = 6,000 − 3,600 = 2,400；E[FM] = 0.5 × 10,000 = 5,000；cov = 5,000 − 3,600 = **+1,400**；組合 var = 0.25(2,400)×2 + 0.5(1,400) = 1,200 + 700 = **1,900**。
> 2. 原題（725）較安全，因為原題負相關、本題正相關（一起違約，就是 2008 的情況）。

# 第 3 章：利率的意義（Ch4＋現值補充講義）

> [!tip] 這章最重要的一句話 **任何資產的價格 = 未來每一筆現金流折回今天的現值加總。殖利率 (YTM) 就是讓「現值 = 價格」的那個利率。所以價格和殖利率永遠反向。**

## 第一性原理：現值 (Present Value, PV)

- 今天 1 元，利率 i，一年後變 $(1+i)$ 元。反過來，一年後的 1 元，今天只值 $\frac{1}{1+i}$。
- n 年後的 CF：$PV = \dfrac{CF}{(1+i)^n}$
- **殖利率／到期收益率 (yield to maturity, YTM)**：讓「未來現金流現值 = 今天價格」的利率。

### 教材圖解｜現值就是沿時間軸往回算

![[01 課堂筆記/貨幣銀行學/附件/期中複習原圖/Fin2007_ch4_meaning_of_interest_rates_p07.png|760]]

> **看圖順序：** 由左往右，每年乘 1.1，是把今天的 100 滾到未來；由右往左，每年除 1.1，是把未來付款折回今天。接下來算年金或債券，只是把每一筆付款各自折現再相加。
> **來源：** [[01 課堂筆記/貨幣銀行學/附件/期中複習原圖/Fin2007_ch4_meaning_of_interest_rates.pdf#page=7|Fin2007_ch4_meaning_of_interest_rates，PDF 第 7 頁]]。

## 四種信用工具（一個貫穿案例：利率 10%）

### 1. 年金：每年固定付（練習題 Q8）

每年年底付 C，共 n 年。推導：

$$PV = \frac{C}{1+i} + \frac{C}{(1+i)^2} + \cdots + \frac{C}{(1+i)^n}$$

這是首項 $\frac{C}{1+i}$、公比 $\frac{1}{1+i}$ 的等比級數，加總後：

$$PV = C \times \frac{1 - (1+i)^{-n}}{i}$$

Q8：每年 2,000、5 年、10%，提示 $1.10^{-5} = 0.6209$

- 年金因子 = (1 − 0.6209) / 0.10 = 3.791
- PV = 2,000 × 3.791 = **7,582**

### 2. 固定付款貸款 Fixed-payment loan（練習題 Q9）

- 每期付一樣金額 FP，同時還利息＋本金（房貸、車貸）。
- 原理：**銀行借你的錢 = 你未來所有還款的現值**。
- Q9：借 10,000，10%，3 年。$1.10^{-3} = 0.7513$
    - 因子 = (1 − 0.7513)/0.10 = 2.487
    - 10,000 = FP × 2.487 → **FP = 4,021**

### 3. 附息債券 Coupon bond（練習題 Q10）

- **面額 (face value / par)**：到期還的本金，通常 1,000。
- **票面利率 (coupon rate)**：每年配息 ÷ 面額。
- 價格 = 配息的年金現值 + 面額的現值：

$$P = C \times \frac{1-(1+i)^{-n}}{i} + \frac{F}{(1+i)^n}$$

Q10(a)：面額 1,000、票面 4%（每年 40）、3 年、YTM 6%，$1.06^{-3} = 0.8396$

- 配息現值 = 40 × (1 − 0.8396)/0.06 = 40 × 2.673 = 106.92
- 面額現值 = 1,000 × 0.8396 = 839.62
- **P = 946.54**

Q10(b) 不用算的規則（必考）：

|YTM vs 票面利率|價格|
|---|---|
|YTM = 票面利率|= 面額（平價）|
|YTM > 票面利率|< 面額（折價）|
|YTM < 票面利率|> 面額（溢價）|

YTM 4% → 價格 1,000；YTM 3% → 高於 1,000。

### 4. 貼現債券 Discount bond 與永續債券 Perpetuity（練習題 Q11、Q12）

- **貼現債券（零息債）**：不配息，低於面額買，到期拿面額。一年期：$i = \dfrac{F - P}{P}$
    - Q11：(1,000 − 925)/925 = **8.11%**
- **永續債券 (perpetuity / consol)**：每年付 C 直到永遠。把年金公式 n→∞，$(1+i)^{-n}\to 0$：

$$P = \frac{C}{i} \quad\Leftrightarrow\quad i = \frac{C}{P}$$

- Q11：60/800 = **7.5%** → 貼現債券殖利率較高。
- **遞延永續**（Q12）：第 4 年才開始付 200。
    - 站在「第一筆前一年」＝第 3 年底：200/0.10 = 2,000
    - 折回今天：2,000 × $1.10^{-3}$ = 2,000 × 0.7513 = **1,503**
    - **陷阱：是折 3 年不是 4 年**，因為 C/i 給的是「第一筆付款前一期」的價值。

## 報酬率 ≠ 利率

- **報酬率 (rate of return)**：$R = \dfrac{C + P_{t+1} - P_t}{P_t}$ = **當期收益率 (current yield)** + **資本利得率 (capital gain)**。
- 只有持有到期，報酬率才等於 YTM。利率上升 → 已持有的長債價格跌 → 報酬率可能變負。
- **實質利率 (real interest rate)**：費雪方程式 (Fisher equation) $i = r + \pi^e$ → $r = i - \pi^e$。

## 存續期間 Duration（練習題 Q13、Q14）

- **存續期間 (duration, DUR)**：投資人平均要等多久才拿到錢，用每筆現值當權重。
- 白話：**存續期間越長，價格對利率越敏感。**
- 永續債（或固定股利永續的股票）：$DUR = \dfrac{1+i}{i}$
    - Q13：i = 5% → 1.05/0.05 = **21 年**
- 價格變動近似：

$$\frac{\Delta P}{P} \approx -DUR \times \frac{\Delta i}{1+i}$$

- Q14：P = 950、DUR = 4.2、i 從 5% 到 6%
- %ΔP = −4.2 × 0.01/1.05 = **−4%**；金額 = 0.04 × 950 = **跌 38 元**
- **陷阱：分母用舊的 (1+i) = 1.05**；Δi 用小數 0.01，不是 1。

## 會怎麼考、陷阱在哪？

- 一定給提示值（如 $1.10^{-5}$），**看到提示就知道要用年金公式**。
- 年金因子要記成「(1 − 提示值)/i」。
- 遞延永續：折回的年數 = 第一筆付款年 − 1。
- 價格與殖利率反向；溢價／折價判斷只要比較 YTM 與票面利率。

## 本章練習（同一案例改變數）

# 第 4 章：利率為什麼會變（Ch5）

> [!tip] 這章最重要的一句話 **兩種看法、同一個答案：債券市場看（價格在縱軸，價格↓ = 利率↑）；貨幣市場看（利率在縱軸）。畫圖題先判斷「哪條線移、往哪移」，再用「價格與利率反向」換算。**

## 架構一：債券供需 (bond supply and demand)

- **債券需求 (Bd)**：想買債券的人。價格越低（利率越高）越想買 → 向右下傾斜。
- **債券供給 (Bs)**：發債借錢的人。價格越高（借錢越便宜）越想發 → 向右上傾斜。

|什麼變了|哪條線|方向|債券價格|利率|
|---|---|---|---|---|
|財富增加|Bd|右移|↑|↓|
|預期未來利率上升（債券預期報酬↓）|Bd|左移|↓|↑|
|預期通膨上升|Bd 左移、Bs 右移|—|↓|↑（費雪效果）|
|債券風險上升|Bd|左移|↓|↑|
|債券流動性上升|Bd|右移|↑|↓|
|景氣擴張（企業投資機會多）|Bs|右移|↓|↑|
|**政府赤字擴大、發債（Q21）**|**Bs**|**右移**|**↓**|**↑**|

# 第 5 章：利率的風險結構與期限結構（Ch6）

> [!tip] 這章最重要的一句話 **同期限不同利率 → 看違約風險、流動性、稅（風險結構）；不同期限不同利率 → 看預期未來短期利率＋期限溢酬（期限結構）。殖利率曲線倒掛 = 市場預期短期利率將下降。**

## 風險結構 (risk structure)：同期限，為什麼利率不同？

- **違約風險 (default risk)**：可能拿不回錢 → 要多給利率 → **風險溢酬 (risk premium)** = 公司債利率 − 同期限公債利率。
- **逃向安全資產 (flight to safety)**：公司違約風險上升 → 公司債需求左移（價跌、利率升），公債需求右移（價漲、利率降）→ 利差從兩端擴大。
- **流動性 (liquidity)**：越難變現越要多給利率。
- **稅 (income tax)**：美國地方政府債（municipal bonds）利息免稅 → 投資人接受較低利率。
- 投資等級門檻：Moody's Baa3／S&P、Fitch BBB−；以下叫垃圾債 (junk bonds)。

> **看圖順序：** 左圖公司債需求左移，價格下跌、殖利率上升；右圖公債需求右移，價格上升、殖利率下降。信用利差從兩邊拉大。比較時要選同期限債券。
> **來源：** [[01 課堂筆記/貨幣銀行學/附件/期中複習原圖/Fin2007_ch6_risk_and_term_structure.pdf#page=10|Fin2007_ch6_risk_and_term_structure，PDF 第 10 頁]]。

## 期限結構 (term structure)：三個理論

要解釋三個事實：(1) 不同期限利率一起動；(2) 短利低時曲線常上斜、短利高時常倒掛；(3) 曲線通常向上。

|理論|核心假設|長期利率|解釋得了|
|---|---|---|---|
|預期理論 (expectations theory)|不同期限債券完全替代|= 未來短期利率預期的平均|事實 1、2，不能解釋 3|
|市場區隔理論 (segmented markets)|完全不能替代|各自供需|只能解釋 3|
|流動性溢酬理論 (liquidity premium theory)|可替代但偏好短期|= 預期平均 + 期限溢酬|三個都可以|

- **陷阱 1：平均要包含「今年」的利率**，n 年期就是 n 個數字平均。
- **陷阱 2：** 流動性溢酬理論下，微幅上斜的曲線可能代表「預期短利不變」；要大幅上斜才代表預期上升。

# 第 6 章：股票市場與效率市場假說（Ch7）

> [!tip] 這章最重要的一句話 **股價 = 未來股利的現值。效率市場假說說：價格已反映所有可得資訊，只有「新消息」能讓價格動，而新消息無法預測，所以股價像隨機漫步。**

## 股票怎麼定價

- 股東是**剩餘請求權人 (residual claimant)**：最後才分錢，股利 (dividend) 不保證。
- **一期評價模型 (one-period valuation model)**（Q18）：

$$P_0 = \frac{Div_1 + P_1}{1 + k_e}$$

- $k_e$：**要求報酬率 (required return on equity)**
- Q18：(1.50 + 42)/1.12 = 43.5/1.12 = **38.84**
- **高登成長模型 (Gordon growth model)**（Q17）：股利每年以 g 成長，永遠。推導：成長型永續年金

$$P_0 = \frac{D_0(1+g)}{k_e - g} = \frac{D_1}{k_e - g}\quad(\text{需要 } k_e > g)$$

- Q17：3.00 × 1.03/(0.08 − 0.03) = 3.09/0.05 = **61.80**
- **陷阱：題目說「剛付完」D₀ 就要乘 (1+g)；說「明年將付」就是 D₁，不要再乘。**

## 預期怎麼形成

- **適應性預期 (adaptive expectations)**：只看過去數據慢慢調整。
- **理性預期 (rational expectations)**：用所有可得資訊做出的最佳預測（不代表一定準，但不會有系統性錯誤）。
- **效率市場假說 (efficient market hypothesis, EMH)**：把理性預期用在金融市場 → 價格反映所有可得資訊 → 沒有未被利用的獲利機會 (unexploited profit opportunity)。

## 練習題 Q1 標準答案結構（簡答直接背邏輯）

1. EMH：價格完全反映所有可得資訊。
2. 若是 AR(1) 且係數遠小於 1：價格會回到平均 → 用過去價格就能預測漲跌 → 有沒被利用的獲利機會，會被套利掉。
3. 所以價格只會因新消息變動，新消息不可預測 → 隨機漫步。

## 會怎麼考、陷阱在哪？

- **EMH 不代表「價格永遠正確」或「每個人都要理性」**，只要有夠多聰明錢套利即可。
- **好消息不一定股價漲**：若消息不如預期，股價照樣跌（「已反映」）。
- 異常現象：小公司效應、一月效應、過度反應、均值回歸、泡沫——簡答可能問「哪個違反 EMH」。
- 可預測性 ≠ 風險：TSMC vs 0050 討論的是風險（波動）而不是可預測性。

# 第 7 章：賽局理論——策略與信念

> [!tip] 這章最重要的一句話 **先找「嚴格優勢策略」（不管對方怎麼做都更好）；沒有的話找「納許均衡」（雙方都在對方策略下做最佳回應，誰都不想單方面改）。均衡不一定是對大家最好的結果（囚犯困境），也可能不只一個（銀行擠兌）。**

## 名詞

- **賽局 (game)**：你的最佳決定取決於別人的決定。
- **報酬矩陣 (payoff matrix)**：每格「(你, 對方)」。
- **嚴格優勢策略 (strictly dominant strategy)**：不論對方選什麼，這個選擇給你的報酬都**嚴格較高**。
- **被支配策略 (dominated strategy)**：永遠比另一個差，理性的人不會選。
- **反覆刪除被支配策略 (iterated deletion of dominated strategies)**：刪掉後大家都知道刪了，再刪下一輪。
- **最佳回應 (best response)**：給定對方策略下，你最好的選擇。
- **納許均衡 (Nash equilibrium)**：每個人的策略都是對其他人策略的最佳回應。

## 完整推導（練習題 Q5：成績賽局＝囚犯困境）

||對方 α|對方 β|
|---|---|---|
|你 α|0, 0|3, −1|
|你 β|−1, 3|1, 1|

- 對方選 α：你選 α 得 0、選 β 得 −1 → α 較好（0 > −1）
- 對方選 β：你選 α 得 3、選 β 得 1 → α 較好（3 > 1）
- **α 是嚴格優勢策略**；對方對稱 → **納許均衡 (α, α) = (0, 0)**
- 但雙方都偏好 (β, β) = (1, 1)：**個人理性 ≠ 集體最好**。

## 完整推導（練習題 Q6：猜 2/3 平均數）

- 第一輪：就算全部人選 100，平均 100，2/3 × 100 ≈ 66.7 → **大於 67 的數字永遠不會贏，刪掉**。
- 第二輪：大家都知道沒人選 >67 → 平均最多 67 → 2/3 × 67 ≈ 44.7 → **刪掉大於 45**。
- 一直刪下去 → 理論上收斂到 1（共同知識理性）。實際課堂答案會高於 1，因為不是每個人都推到底。

## 完整推導（練習題 Q7：合夥賽局）

### 題目完整敘述（依原題翻譯）

兩位合夥人共同經營一家公司，並且**平均分配公司的利潤**。每位合夥人各自決定要投入多少努力：合夥人 1 選擇努力程度 $s_1$，合夥人 2 選擇努力程度 $s_2$。

給定自己對另一位合夥人努力程度的看法，每個人的最佳努力選擇，也就是**最佳回應（best response）**，分別為：

$$
\hat{s}_1 = 1 + 0.25s_2
$$

$$
\hat{s}_2 = 1 + 0.25s_1
$$

**納許均衡（Nash equilibrium）**是一組努力程度，使得每位合夥人的努力，都是對另一位合夥人努力的最佳回應。

**問題：請求出兩位合夥人在納許均衡下，各自投入的努力程度。**

> 題目來源：Fin2007_F26_practice_midterm，Q7，第 2 頁；答案核對：Fin2007_F26_practice_midterm_aks，第 3 頁。

### 先理解：這兩條式子在說什麼？

|符號|意思|
|---|---|
|$s_1$、$s_2$|兩位合夥人各自實際選擇的努力程度|
|$\hat{s}_1$、$\hat{s}_2$|給定對方的努力時，自己最想選的努力程度|
|$s_1^{*}$、$s_2^{*}$|均衡時兩人各自選擇的努力；星號是均衡的標記，不是乘號|

例如，若合夥人 2 投入 $s_2=2$，合夥人 1 的最佳回應就是：

$$
\hat{s}_1 = 1 + 0.25\times 2 = 1.5
$$

但 **$(1.5,2)$ 還不是均衡**。因為當合夥人 1 投入 1.5 時，合夥人 2 最想投入的是：

$$
\hat{s}_2 = 1 + 0.25\times 1.5 = 1.375
$$

合夥人 2 會想改變原本的選擇。**只滿足一個人的最佳回應還不夠；兩個人必須同時都不想單方面改變。**

### 第一步：把「互為最佳回應」寫成聯立方程式

均衡時，實際選擇必須等於最佳回應，因此：

$$
\begin{aligned}
s_1^{*} &= 1 + 0.25s_2^{*} \\[4pt]
s_2^{*} &= 1 + 0.25s_1^{*}
\end{aligned}
$$

題目已經給了最佳回應，所以這題直接解聯立方程式即可，不需要再對利潤函數微分。

### 第二步：確認兩人的均衡努力相同

將第一式減去第二式：

$$
s_1^{*}-s_2^{*} = 0.25(s_2^{*}-s_1^{*})
$$

移項後得到：

$$
1.25(s_1^{*}-s_2^{*})=0
\quad\Longrightarrow\quad
s_1^{*}=s_2^{*}
$$

所以可以把兩人的均衡努力都記為 $s^{*}$。這裡是由方程式證明兩人相同；**不能只因為賽局對稱，就認定所有賽局的均衡一定對稱。**

### 第三步：代入，求出努力程度

把 $s_1^{*}=s_2^{*}=s^{*}$ 代入其中一式：

$$
\begin{aligned}
s^{*} &= 1 + 0.25s^{*} \\[4pt]
s^{*}-0.25s^{*} &= 1 \\[4pt]
0.75s^{*} &= 1 \\[4pt]
s^{*} &= \frac{1}{0.75}=\frac{4}{3}
\end{aligned}
$$

因此，本題唯一的納許均衡為：

$$
\boxed{(s_1^{*},s_2^{*})=\left(\frac{4}{3},\frac{4}{3}\right)}
$$

也就是**每人各投入約 1.33 單位的努力**。這是努力程度，不是每人的利潤，也不是兩人努力的合計。

### 第四步：代回檢查，為什麼沒有人想改？

當對方投入 $4/3$ 時，自己的最佳回應為：

$$
1 + 0.25\times\frac{4}{3}
=1+\frac{1}{3}
=\frac{4}{3}
$$

兩人都一樣：**固定對方的選擇，自己目前的努力已經是最佳選擇。** 因此沒有人能透過單方面改變努力，讓自己的報酬更好，符合納許均衡定義。

### 另一種解法：不先設兩人相同，直接代入

把第二人的最佳回應代入第一式：

$$
\begin{aligned}
s_1^{*} &= 1 + 0.25(1 + 0.25s_1^{*}) \\[4pt]
&=1.25+0.0625s_1^{*} \\[4pt]
0.9375s_1^{*} &= 1.25 \\[4pt]
s_1^{*} &= \frac{1.25}{0.9375}=\frac{4}{3}
\end{aligned}
$$

再代回第二式，得到 $s_2^{*}=4/3$。這也確認沒有另一組不對稱的均衡。

### 這題真正要記住什麼？

- **最佳回應是「給定對方，自己怎麼選」；納許均衡是「兩人的最佳回應同時成立」。**
- 係數 $0.25>0$ 表示對方越努力，自己的最佳努力也越高，稱為「策略互補」。
- 均衡不代表兩人共同利益最大。本題只要求納許均衡，沒有要求求出合作下的最適努力。

> [!tip] 考試精簡寫法
> 均衡需滿足 $s_1=1+0.25s_2$ 與 $s_2=1+0.25s_1$。兩式相減得 $1.25(s_1-s_2)=0$，故 $s_1=s_2=s$。代入得 $0.75s=1$，所以均衡努力為 $(s_1^{*},s_2^{*})=(4/3,4/3)$。此時兩人皆在對方努力給定下選擇最佳回應。

## 會怎麼考、陷阱在哪？

- **陷阱 1：每格第一個數字是「列」的玩家（你）**，比較時固定對方、看同一欄上下比。
- **陷阱 2：要找「所有」納許均衡**（擠兌賽局有兩個）。逐格檢查：兩人都不想單方面改就是均衡。
- **陷阱 3：** 有嚴格優勢策略 ≠ 結果有效率。

# 第 8 章：資訊不對稱與信用配給（Ch8＋信用配給講義）

> [!tip] 這章最重要的一句話 **借款人知道得比貸款人多。能「可信地」承諾給貸款人的那部分收入叫可抵押收入 (pledgeable income)；只要它小於需要借的錢，再好的專案也借不到錢——這就是信用配給。**

## 兩種資訊不對稱（練習題 Q4，必考簡答）

### 題目完整敘述（依原題翻譯）

**逆選擇（adverse selection）與道德風險（moral hazard）有什麼差別？請針對這兩種問題，各舉一個銀行如何處理的例子。**

> 題目與解答來源：Fin2007_F26_practice_midterm_aks，Q4，第 2 頁。

### 先理解：銀行不知道的是什麼？

**資訊不對稱**是指交易雙方掌握的資訊不同。在貸款中，借款人通常比銀行更清楚自己的還款能力、專案風險，以及拿到錢後會怎麼使用。

區分兩種問題時，先看「借錢前或借錢後」，再看銀行無法觀察的是「借款人的類型」還是「借款人的行為」。

| 比較項目    | 逆選擇（adverse selection） | 道德風險（moral hazard）       |
| ------- | ---------------------- | ------------------------ |
| 發生時間    | **放款前**，挑選借款人時         | **放款後**，借款人使用資金時         |
| 隱藏的是什麼  | **隱藏資訊**：借款人的風險類型、還款能力 | **隱藏行為**：借款人拿到錢後的努力與冒險程度 |
| 銀行面臨的問題 | 無法充分辨別好、壞風險，可能把錢借給高風險者 | 無法充分觀察或約束借款人的行動，還款機率可能下降 |
| 核心對策    | **事前篩選（screening）**    | **事後監督（monitoring）**     |
| 具體例子    | 放款前查信用紀錄、收入與現金流        | 放款後追蹤財報、查核貸款用途           |
| 記憶句     | **借之前：不知道你是哪一種人。**     | **借之後：不知道你會怎麼做。**        |

### 例子一：逆選擇——先分辨「要借給誰」

兩位申請人都想借 100 萬元。一位收入穩定、還款機率高，另一位的投資專案風險很高，但銀行只看申請表，無法充分辨別。

高風險借款人可能更願意接受高利率，因為若專案失敗，部分損失由銀行承擔。若銀行一味提高利率，較安全的借款人可能退出，留下的申請者反而更危險，這就是逆選擇可能造成的問題。

**銀行怎麼處理？** 在放款前進行篩選，例如查信用紀錄、核對收入與負債、評估專案現金流，降低把錢借給高風險者的機會。

### 例子二：道德風險——再確認「錢借出去後怎麼用」

借款人申請貸款時說要買設備，拿到錢後卻改做高風險投資。銀行不容易即時發現，而投資失敗會使還款更困難。

問題的重點是：**借到錢後，借款人的行為可能改變，而且銀行難以觀察或約束。** 不一定涉及說謊；減少努力、選擇更高風險的專案，也可能是道德風險。

**銀行怎麼處理？** 放款後持續監督，例如要求定期提供財報、查核資金用途，並透過貸款合約的限制條款約束過度舉債或高風險投資。

### 考試簡答可以這樣寫

> 逆選擇發生在**放款前**，因為銀行無法充分辨別借款人的風險類型，可能選到較容易違約的借款人。銀行可透過**篩選**，例如查核信用紀錄與收入，降低此問題。
>
> 道德風險發生在**放款後**，因為借款人可能採取銀行難以觀察的行動，使還款機率下降。銀行可透過**監督**，例如追蹤財報與查核貸款用途，降低此問題。

### 延伸：這和銀行為什麼存在有什麼關係？

銀行可以集中資源做信用調查，透過長期往來了解借款人，並在放款後持續監督，減少個別儲蓄者自行查核的成本。

若研究資訊公開，其他投資人可能直接使用，卻不分攤研究成本，這叫**搭便車問題（free-rider problem）**。銀行能把調查結果用於私人貸款決策，較能保留資訊帶來的收益，因而**減輕**搭便車問題。

> [!tip] 避免混淆
> Q4 各寫一個清楚的對策即可：**逆選擇 → 放款前篩選；道德風險 → 放款後監督。** 擔保品、自有資金與限制條款可能同時影響多種誘因，不必硬分成只能處理其中一種問題。

## 模型一：道德風險下的信用配給（練習題 Q28）

設定：投資 I = 100；成功得 R = 150、失敗 0；認真成功率 pH = 0.9；偷懶成功率 pL = 0.5，偷懶有私人利益 B = 20；利率 0，貸款人競爭。

**(a) 要讓她認真，成功時她自己至少要留多少 Rb？**

- 認真的期望：$p_H R_b$；偷懶的期望：$p_L R_b + B$
- 誘因相容條件 (incentive compatibility)：$p_H R_b \ge p_L R_b + B$
- → $(p_H - p_L) R_b \ge B$ → $R_b \ge \dfrac{B}{\Delta p} = \dfrac{20}{0.4} = 50$
- 成功時能給貸款人的最多是 R − 50 = 100
- **可抵押收入** = $p_H(R - B/\Delta p) = 0.9 × 100 = 90$

**(b) 她至少要有多少自有資金 Ā？**

- 貸款人借 I − A，期望收回最多 90 → 要 $I - A \le 90$
- $\bar A = 100 - 90 = 10$

**(c) A = 5 能借到嗎？**

- 要借 95 > 90 → **借不到**
- 但專案 NPV = 0.9 × 150 − 100 = 35 > 0，是好專案 → **這就是信用配給**。
- 白話：她再願意付高利率也沒用，因為多付會讓她自己留下的錢少於 50 → 她會偷懶 → 貸款人更收不回。

## 模型二：私人資訊下的信用配給（練習題 Q29）

設定：I = 100，成功 R = 250；好借款人成功率 p = 0.8、壞的 q = 0.2；沒有自有資金；利率 0。

**(a) 看得到類型**

- 好：$0.8 R_\ell = 100$ → $R_\ell = 125$（成功時還 125）
- 壞：就算全拿 250，期望 0.2 × 250 = 50 < 100 → **不借**

**(b) 看不到類型、一半一半**

- 平均成功率 m = 0.5(0.8) + 0.5(0.2) = 0.5
- 損益兩平：$m R_\ell = 100$ → $R_\ell = 200$
- 對好人賺：0.8 × 200 − 100 = **+60**；對壞人虧：0.2 × 200 − 100 = **−60**
- **結論：好借款人被迫補貼壞借款人（交叉補貼），付 200 而不是 125。** 若壞人比例更高，要求的 Rℓ 可能超過 R = 250，市場直接關閉。

## 會怎麼考、陷阱在哪？

- **陷阱 1：** 逆選擇 vs 道德風險只看「時間點」：借之前 vs 借之後。
- **陷阱 2：** 可抵押收入是乘 $p_H$（她會認真），不是 $p_L$。
- **陷阱 3：** Δp = pH − pL，不是 pH。
- **陷阱 4：** 信用配給的重點是「NPV > 0 卻借不到」，不是「專案爛」。
- 延伸觀念：提高利率反而可能吸引更多壞借款人（Stiglitz–Weiss），所以銀行選擇「限量」而不是「漲價」。

# 第 9 章：銀行經營——流動性、資本、利率風險（Ch9）

> [!tip] 這章最重要的一句話 **銀行用短期、高流動、安全的負債（存款）去買長期、低流動、有風險的資產（貸款）。流動性風險、償債能力風險、利率風險，全都來自這個「期限錯配」。**

## 資產負債表 (balance sheet)

$$\text{資產 Assets} = \text{負債 Liabilities} + \text{銀行資本 Bank capital}$$

- **銀行資本 = 淨值 (net worth) = 權益 (equity)**，三個名字同一件事，考卷三個都會用。
- 負債：支票存款、儲蓄／定存、借款。資產：**準備金 (reserves)**、證券、貸款。
- **準備金** = **法定準備 (required reserves)** + **超額準備 (excess reserves)**
- **法定準備率 (required reserve ratio)**：存款中必須留作準備的比例。

## 流動性：存款流出（練習題 Q23）

存款 500、準備金 80、法定準備率 10%。

- (a) 法定準備 = 0.10 × 500 = 50；**超額準備 = 80 − 50 = 30**
- (b) 流出 x，準備金和存款都減 x：$80 - x \ge 0.10(500 - x)$
    - $80 - x \ge 50 - 0.1x$ → $30 \ge 0.9x$ → **x ≤ 33.3**
    - **陷阱：答案不是 30！** 存款減少時，法定準備也跟著減少（每流出 1 元，法定準備少 0.1）。

## 資本與報酬（練習題 Q24）

- **權益乘數 (equity multiplier, EM)** = 資產 / 資本 = 400/40 = **10**
- **資產報酬率 (ROA)** = 稅後淨利 / 資產 = 5/400 = **1.25%**
- **權益報酬率 (ROE)** = 稅後淨利 / 資本 = 5/40 = **12.5%**
- 關係：**ROE = ROA × EM**（1.25% × 10 = 12.5%）
- 取捨：資本少 → EM 大 → ROE 高（股東爽）；但虧損時較容易倒（安全性低）。

## 風險加權資產 (risk-weighted assets, RWA)（練習題 Q25）

> [!info] 題目與來源
> 以下 Q25–Q27、Q30 已核對老師的 `Fin2007_F26_practice_midterm.pdf`（第 5–6 頁）及 `_aks.pdf` 解答（第 7–8 頁），題意以中文重述，並補上中間步驟。Q28、Q29 已依主題編排在前面的第 8 章。
> Q25–Q27 的金額單位均為**百萬美元**；Q30 則是**美元**。本題權重與 7% 資本要求是題目指定的計算設定。

### 題目敘述

銀行各類資產的風險權重如下，要求銀行資本至少等於風險加權資產的 7%。

| 資產類別                                    | 風險權重 |
| --------------------------------------- | ---: |
| 準備金、政府公債（Treasury securities）           |   0% |
| 房地美／房利美貸款（Freddie Mac／Fannie Mae loans） |  20% |
| 住宅抵押貸款（residential mortgages）           |  50% |
| 商業貸款（commercial loans）                  | 100% |
|                                         |      |

**(a)** 某銀行持有準備金 40、公債 60、房地美／房利美貸款 100、住宅房貸 120、商業貸款 180，銀行資本為 22。請判斷是否符合資本要求。

**(b)** **另一家銀行**有尚未用於支持風險資產的資本 2.1。若全用來支持新增房地美／房利美貸款，最多可增加多少？若改成全用來支持商業貸款，又可增加多少？兩種情況分別計算。

### 解題觀念：先算風險資產，再算需要多少資本

RWA 是將各項資產金額乘上指定風險權重後加總，並非資產市價或預期損失。資本則是吸收損失的權益，不能和準備金混為一談。

$$RWA=\sum_j w_j A_j,\qquad K_{\min}=0.07\times RWA$$

只要實際資本 $K\ge K_{\min}$ 就合格；恰好相等也合格。

### (a) 逐步計算

**步驟 1：逐項乘上風險權重。**

|資產|金額|權重|計入 RWA 的金額|
|---|---:|---:|---:|
|準備金|40|0%|0|
|公債|60|0%|0|
|房地美／房利美貸款|100|20%|20|
|住宅房貸|120|50%|60|
|商業貸款|180|100%|180|
|合計|500|—|260|

$$RWA=40(0)+60(0)+100(0.2)+120(0.5)+180(1)=260$$

**步驟 2：計算最低所需資本。**

$$K_{\min}=260\times0.07=18.2$$

**步驟 3：比較實際資本與門檻。**

$$22>18.2\quad\Rightarrow\quad\boxed{\text{符合資本要求}}$$

補充檢查：資本充足率 $22/260\approx8.46\%>7\%$；超過最低要求的資本為 $22-18.2=3.8$ 百萬美元。

### (b) 逐步計算

**步驟 1：把多餘資本換成可新增的 RWA。**

$$\Delta RWA_{\max}=\frac{2.1}{0.07}=30$$

**步驟 2：把 RWA 換回各種貸款的實際金額。** 若新增貸款為 $X$，權重為 $w$，就須滿足 $0.07wX\le2.1$。

|新增資產的選擇|計算|最多新增金額|
|---|---|---:|
|全為房地美／房利美貸款，$w=0.2$|$X=30/0.2$|150 百萬美元|
|全為商業貸款，$w=1$|$X=30/1$|30 百萬美元|

**步驟 3：代回驗算。** $150\times0.2\times0.07=2.1$；$30\times1\times0.07=2.1$，都剛好用完資本空間。

> [!warning] 容易混淆的地方
> - 原題 (b) 明寫「另一家銀行」，所以 2.1 是獨立給定的條件，**不是**由 (a) 的 $22-18.2$ 得到。
> - 150 與 30 是兩個替代方案，不能同時增加這兩筆。若混合增加 $F$ 的房地美／房利美貸款與 $C$ 的商業貸款，須滿足 $0.2F+C\le30$。
> - 此處算的是資本限制下的最大承擔量；資本空間並不等於已備妥同額可貸出的現金。

## 利率風險一：缺口分析 (gap analysis)（練習題 Q26）

### 題目敘述

某銀行有 45 百萬美元的利率敏感資產（RSA），以及 60 百萬美元的利率敏感負債（RSL）。這些資產與負債會在一年內重新訂價，其餘資產負債採固定利率。若利率上升 **1.5 個百分點**，請用基本缺口分析，估計銀行一年內的利潤變化。

### 解題流程

**步驟 1：辨認要算的量。** 本題問的是一年內利潤的變化；依基本缺口分析，只考慮重新訂價造成的利息收入與支出變動，其他條件不變。

**步驟 2：算出缺口。**

$$GAP=RSA-RSL=45-60=-15\quad\text{（百萬美元）}$$

負缺口代表會重新訂價的負債比資產多，升息會讓支出增加得更多。

**步驟 3：把百分點換成小數。**

$$\Delta i=1.5\text{ 個百分點}=0.015$$

**步驟 4：計算利潤變化。**

$$\Delta\pi\approx GAP\times\Delta i=(-15)(0.015)=-0.225\quad\text{（百萬美元）}$$

因此，**一年內利潤減少 225,000 美元（22.5 萬美元）**。題目未給原始利潤，不能據此求出變動後的利潤總額。

**步驟 5：拆開收入與支出驗算。**

- 利息收入增加：$45\times0.015=0.675$ 百萬美元。
- 利息支出增加：$60\times0.015=0.900$ 百萬美元。
- 利潤淨變化：$0.675-0.900=-0.225$ 百萬美元，與缺口公式一致。

> [!tip] 考試判斷
> $GAP<0$ 時，升息不利、降息有利；$GAP>0$ 時方向相反。這是基本模型的估計，依題意採共同利率變動，不另調整年內重新訂價的時點。

## 利率風險二：存續期間缺口 (duration gap)（練習題 Q27）

### 題目敘述

某銀行資產市值為 100 百萬美元，平均存續期間 3 年；負債市值為 90 百萬美元，平均存續期間 2 年。若利率由 10% 上升至 11%，請計算存續期間缺口，並估計銀行淨值市值的變化。

### 符號與公式

$A$ 為資產市值，$L$ 為負債市值，$NW=A-L$ 為淨值；$D_A,D_L$ 分別為資產、負債存續期間。$i$ 使用變動前利率。

$$DGAP=D_A-\frac{L}{A}D_L$$

$$\frac{\Delta NW}{A}\approx-DGAP\frac{\Delta i}{1+i},\qquad\Delta NW\approx-A\times DGAP\times\frac{\Delta i}{1+i}$$

### 解題流程

**步驟 1：整理條件與初始淨值。**

$$A=100,\ L=90,\ D_A=3,\ D_L=2,\ NW=100-90=10$$

$$i=0.10,\qquad\Delta i=0.11-0.10=0.01$$

**步驟 2：算存續期間缺口。**

$$DGAP=3-\frac{90}{100}\times2=3-1.8=\boxed{1.2\text{ 年}}$$

負債規模只有資產的 90%，所以要先用 $L/A$ 調整，不能直接用 $3-2$。

**步驟 3：算淨值變動占原資產的比例。**

$$\frac{\Delta NW}{A}\approx-1.2\times\frac{0.01}{1.10}=-0.010909\approx-1.09\%$$

**步驟 4：乘回原資產金額。**

$$\Delta NW\approx100(-0.010909)=-1.0909\quad\text{（百萬美元）}$$

答案：**淨值市值約減少 1.09 百萬美元（老師解答四捨五入為 1.1 百萬）**；新淨值約 $10-1.0909=8.9091$ 百萬美元。

**步驟 5：分開估計資產與負債價格變動，驗證方向。**

$$\Delta A\approx-100(3)\frac{0.01}{1.10}=-2.7273$$

$$\Delta L\approx-90(2)\frac{0.01}{1.10}=-1.6364$$

$$\Delta NW=\Delta A-\Delta L\approx-2.7273-(-1.6364)=-1.0909$$

升息使資產與負債市值都下跌，但資產跌得更多，所以淨值減少。

> [!warning] 分母不能看錯
> $-1.09\%$ 是 $\Delta NW/A$，不是 $\Delta NW/NW$。若題目問淨值本身的百分比變化，則為 $-1.0909/10\approx-10.91\%$。存續期間法是一階近似，所以答案使用「約」。

### Q26 與 Q27 怎麼分？

| 比較項目 | Q26：缺口分析            | Q27：存續期間缺口                       |
| ---- | ------------------- | -------------------------------- |
| 題目關心 | 一年內利潤／淨利息收入變化       | 淨值的市值變化                          |
| 需要資料 | 利率敏感資產與負債           | 資產與負債市值及存續期間                     |
| 計算核心 | $(RSA-RSL)\Delta i$ | $-A[D_A-(L/A)D_L]\Delta i/(1+i)$ |
| 本題結果 | 利潤減少 0.225 百萬美元     | 淨值市值約減少 1.09 百萬美元                |

## 會怎麼考、陷阱在哪？

- Q23(b) 的 33.3 vs 30 是經典陷阱。
- RWA 要逐項乘權重，0% 的項目仍要列出來表示有考慮。
- 缺口分析的 Δi 是小數（1.5 個百分點 = 0.015）。
- 升息時：GAP < 0 → 收入減；DGAP > 0 → 淨值減。

## 本章練習（同一間銀行改數字）

> 以下為筆記的延伸練習，不是原題卷新增的小題。每題獨立變更條件，金額均以百萬美元表示。

### 練習 1：提高法定準備率

**題目：** 銀行支票存款 500、準備金 80。把 Q23 的法定準備率改為 20%，求超額準備，以及不賣資產、不借款時可承受的最大存款流出。

**解題：** 法定準備 $=500\times0.2=100$；超額準備 $=80-100=-20$，表示**已短缺 20**。

若流出 $x\ge0$，準備金與存款同時下降：

$$80-x\ge0.2(500-x)\Rightarrow-20\ge0.8x\Rightarrow x\le-25$$

不存在符合條件的非負流出量；**銀行起初就不合格，連流出 0 都未符合要求**，不能把 −25 解讀成可提款金額。

### 練習 2：降低銀行資本

**題目：** 銀行資產維持 400、稅後淨利維持 5，把 Q24 的資本改為 25。求 EM、ROA、ROE，並驗證關係式。

**解題：**

$$EM=\frac{400}{25}=16,\quad ROA=\frac5{400}=1.25\%,\quad ROE=\frac5{25}=20\%$$

驗算：$ROA\times EM=1.25\%\times16=20\%=ROE$。在本題資產與淨利固定的設定下，資本減少讓槓桿與 ROE 上升，也讓吸收虧損的緩衝變小。

### 練習 3：增加商業貸款

**題目：** Q25(a) 的準備金 40、公債 60、房地美／房利美貸款 100、住宅房貸 120、資本 22 都不變，只把商業貸款由 180 改成 250。沿用原風險權重及 7% 要求，判斷是否合格。

**解題：**

$$RWA=40(0)+60(0)+100(0.2)+120(0.5)+250(1)=330$$

$$K_{\min}=330(0.07)=23.1>22$$

因此**不合格，資本短缺 1.1**。資本充足率 $22/330\approx6.67\%<7\%$，也得到相同結論。

### 練習 4：負債存續期間變長

**題目：** Q27 的資產 100、資產存續期間 3 年、負債 90 不變，只把負債存續期間改為 4 年。利率仍由 10% 升至 11%，求 DGAP 與淨值變化。

**解題：**

$$DGAP=3-\frac{90}{100}(4)=-0.6\text{ 年}$$

$$\frac{\Delta NW}{A}\approx-(-0.6)\frac{0.01}{1.10}=0.0054545\approx0.545\%$$

$$\Delta NW\approx100(0.0054545)=+0.54545$$

所以**淨值約增加 0.55 百萬美元**。負債市值約減少 $90(4)(0.01)/1.1=3.2727$，大於資產市值減少的 $100(3)(0.01)/1.1=2.7273$，故資產減負債後的淨值反而上升。

# 第 10 章：銀行擠兌與金融安全網（Diamond–Dybvig、Ch10–11）

> [!tip] 這章最重要的一句話 **擠兌是有兩個均衡的協調賽局：大家都等＝都好；大家都提＝都差。存款保險能消除壞均衡，但會帶來道德風險，所以必須搭配資本要求與監理。**

## 完整推導（練習題 Q30）

### 題目敘述

兩位存款人各存入 **100 美元**，銀行將合計 **200 美元**全部貸出。貸款若持有到期，可收回 **300 美元**；若提前清算，每清算 1 美元的貸款本金，只能收回 **0.5 美元**。

兩位存款人各自選擇提前提款（Withdraw）或等待到期（Wait）。提前提款者有權領取 100 美元；若兩人都提款，就均分銀行當下能籌到的錢；等待者則取得貸款到期後剩下的款項。

**(a)** 寫出報酬矩陣。**(b)** 找出所有純策略納許均衡。**(c)** 說明存款保險如何改變結果，以及它會造成什麼問題。

### (a) 先算四種情況，再填矩陣

**步驟 1：兩人都等。** 不必清算，貸款到期收回 300，兩人均分：

$$300/2=150\quad\Rightarrow\quad(150,150)$$

**步驟 2：只有一人提領。** 設必須清算的貸款本金為 $x$。為了籌出 100 美元，須滿足：

$$0.5x=100\quad\Rightarrow\quad x=200$$

銀行必須清算全部貸款。提款者拿到 100，剩餘貸款為零，等待者到期拿到 0。因此「1 等、2 提」為 $(0,100)$，「1 提、2 等」為 $(100,0)$。

**步驟 3：兩人都提領。** 全數清算只能籌得 $200\times0.5=100$，兩人均分，各得 50，故為 $(50,50)$。

**步驟 4：整理矩陣。** 每格依序是「存款人 1 的報酬、存款人 2 的報酬」；報酬是領回的總金額，尚未扣除原存款 100。

|存款人 1 ＼ 存款人 2|等待 Wait|提領 Withdraw|
|---|---|---|
|等待 Wait|150, 150|0, 100|
|提領 Withdraw|100, 0|50, 50|

### (b) 找所有純策略納許均衡

納許均衡的檢查方式：固定另一人的選擇，看看自己單方面改變選擇能不能拿更多。

|對方的選擇|自己等待所得|自己提領所得|最佳回應|
|---|---:|---:|---|
|等待|150|100|等待|
|提領|0|50|提領|

兩人條件相同，所以最佳回應完全對稱。

1. **（等，等）是均衡：** 任一人改成提領，所得從 150 降為 100，沒人想改。
2. **（提，提）是均衡：** 任一人改成等待，所得從 50 降為 0，沒人想改。
3. **（等，提）不是均衡：** 等的人改成提領，可從 0 提高至 50。
4. **（提，等）不是均衡：** 同理，等的人有誘因改成提領。

因此所有純策略納許均衡為 **（Wait, Wait）與（Withdraw, Withdraw）**。兩人都沒有優勢策略，因為最佳選擇會隨對方的行動改變。

白話：銀行的貸款持有到期足以支付存款，但若大家預期別人會搶先提款，自己也會提款，迫使銀行折價清算，形成擠兌。

### (c) 存款保險的作用與代價

**步驟 1：找出原本搶先提款的原因。** 原模型中，對方提領時，自己等待只拿到 0，因此寧可也去提領拿 50。

**步驟 2：加入可信的保障。** 按老師解答的直覺，等待者的存款受到保障，就不必擔心因別人先提領而血本無歸，能避免恐慌性提款、支持兩人都等待的好結果。

**步驟 3：說明為何均衡中可能不須賠付。** 若兩人都等待，貸款到期回收 300，銀行自行支付每人 150，保險人不必實際支付理賠。這是此題好結果下的結論，並非任何銀行倒閉都不需理賠。

**步驟 4：指出道德風險。** 存款人覺得存款有保障，監督銀行的誘因下降；銀行因而可能承擔更多風險。所以存款保險需要搭配資本要求與監理。

> [!note] 考試作答與模型界線
> 可寫：「可信的存款保險降低擠兌誘因；若大家等待，銀行能以到期回收款支付，保險人毋須理賠。但保障會削弱存款人監督，產生道德風險，因此須搭配資本要求與監理。」
> 原題未給完整保險後支付規則，不宜自行編出唯一的新矩陣。若只設定本金 100 全額受保障，某些狀況下等待與提款可能同得 100；要嚴格宣稱壞均衡必然消失，還需明確指定支付與時點等規則。

## 安全網 (safety net) 其他重點

- 存款保險 (deposit insurance)：美國 FDIC，台灣中央存保。
- 處理倒閉銀行兩法：**償付法 (payoff method)**（只賠保額內）vs **購併法 (purchase and assumption)**（找別家接手，等於全額保障）。
- **大到不能倒**：大銀行倒了衝擊太大 → 政府總會救 → 大額存款人也不監督 → 道德風險更嚴重。
- 監理的「辯證」(regulatory dialectic)：監理 → 銀行找漏洞 → 新監理，本身也是一種賽局。

## 會怎麼考、陷阱在哪？

- 一人提領時，等的人拿 0（不是 50）——銀行為了付 100 必須清算全部貸款。
- 要寫出**所有**純策略納許均衡。
- 簡答「存款保險的代價」答案關鍵字：**moral hazard + 存款人不監督 + 因此需要資本要求與監理**。

## 本章練習

> 以下沿用 Q30：兩人各存 100 美元，貸款本金合計 200，到期回收 300；僅改變提前清算回收率。每題獨立計算，並假設未清算部分仍按本金的 1.5 倍到期回收。

### 練習 1：清算回收率提高到 75%

**題目：** 若每清算 1 美元貸款本金可收回 0.75 美元，重寫報酬矩陣並找出所有純策略納許均衡。

**步驟 1：都等。** 仍收回 300，各得 150。

**步驟 2：一人提領。** 需支付 100，因此清算本金為 $100/0.75=133\frac13$；剩餘本金為 $200-133\frac13=66\frac23$，到期回收 $66\frac23\times1.5=100$。故提款者、等待者各得 100。

**步驟 3：都提。** 清算全部取得 $200(0.75)=150$，每人領 $150/2=75$。

|存款人 1 ＼ 存款人 2|等待|提領|
|---|---|---|
|等待|150, 150|100, 100|
|提領|100, 100|75, 75|

**步驟 4：比較最佳回應。** 對方等，自己等得 150、提得 100；對方提，自己等得 100、提得 75。兩種情況都嚴格偏好等待，故**等待是嚴格優勢策略，唯一純策略納許均衡是（等，等）**。

### 練習 2：清算回收率提高到 100%

**題目：** 若每清算 1 美元本金可完整收回 1 美元，還存在兩人都提領的擠兌均衡嗎？請以報酬與最佳回應說明。

**步驟 1：都等。** 到期各得 150。

**步驟 2：一人提領。** 清算 100 本金就能支付提款者 100；剩餘 100 到期變為 150，全給等待者。

**步驟 3：都提。** 全部清算取得 200，各得 100。

|存款人 1 ＼ 存款人 2|等待|提領|
|---|---|---|
|等待|150, 150|150, 100|
|提領|100, 150|100, 100|

**步驟 4：找均衡。** 不論對方等或提，自己等都得 150，提都得 100。因此**等待為嚴格優勢策略，唯一純策略納許均衡為（等，等），不存在擠兌均衡**。

> [!tip] 兩題比較
> 本模型的擠兌機制是：提前清算折價若足夠嚴重，別人先提領會大幅侵蝕等待者的報酬，產生跟著提款的誘因。回收率 75% 的例子仍有折價，卻已沒有擠兌均衡，所以不能說「只要折價就必然擠兌」。

## 一、優先處理：你曾答錯或反覆追問的觀念

### 1. Q18：先選模型，再代公式【對話已指出的錯法】

你曾問：「18 我這樣算有錯哪？」當時回覆指出，你把一期股票評價題寫成 $P_0=1.5/(12\%-g)$，誤用了高登成長模型。

|看到什麼條件？|用哪一個模型？|公式|
|---|---|---|
|一年後股利、預期賣價、要求報酬率|一期評價模型（one-period valuation model）|$P_0=(D_1+P_1)/(1+k_e)$|
|股利永久以固定速度成長，且 $k_e>g$|高登成長模型（Gordon growth model）|$P_0=D_1/(k_e-g)$|

**Q18 正確做法：** 一年後收到股利 1.5 加賣價 42，再用 12% 折現。

$$P_0=\frac{1.5+42}{1.12}=\boxed{38.84}$$

**當場自問：** 題目有說「永遠固定成長」嗎？沒有，就不能自行補一個 $g$。題目已給未來賣價時，也不能漏掉賣價這筆現金流。

### 2. $D_0$、$D_1$、$g$、$k_e$ 不要混在一起【曾詢問、反覆追問】

|符號|真正意思|考題文字線索|
|---|---|---|
|$D_0$|剛支付的股利|just paid、最近一次股利|
|$D_1$|下一期預期股利|next year、下一期支付|
|$g$|股利的成長率（dividend growth rate）|股利每年增加多少|
|$k_e$|股權必要報酬率（required return on equity）|投資人承擔風險所要求的報酬|

Q17 給 $D_0=3,g=3\%,k_e=8\%$，先換成 $D_1=3(1.03)=3.09$，再算 $P_0=3.09/(0.08-0.03)=61.80$。若題目直接給 $D_1$，就不再乘 $1+g$。

你曾把「必要報酬率維持 10%」稱作「成長率維持 10%」。**兩者用途不同：$g$ 決定未來收款成長多快；$k_e$ 決定未來收款折現多少。**

你也追問過「成長前景變好，風險補償難道不會一起變？」這是合理的模型檢查。新消息可能同時改變 $D_1,g,k_e$；只有題目指定其他條件不變時，才固定其中某些變數。若同時變動，須一起代入，不能直接斷言股價必漲。

### 3. 為什麼好消息讓價格立刻跳升？【反覆追問】

沿用以前的**教學假設**：不配息、必要報酬率 10%，對同一個一年後的預期價格從 418 上修為 462。

$$P_{\text{舊}}=\frac{418}{1.10}=380,\qquad P_{\text{新}}=\frac{462}{1.10}=420$$

不是過了一年才漲；是**今天收到新消息，今天就重新評價未來的收款**。462 已是包含新預期的未來價格，不可再無故乘一次 $1+g$，否則可能重複計入同一段成長。

|要分清楚的報酬|計算|意義|
|---|---|---|
|380 到 420 的價格跳升|$(420-380)/380\approx10.53\%$|原持有人因消息得到的價格變動|
|420 買入後的預期報酬|$(462-420)/420=10\%$|新價格下，往後一年的預期報酬|

**好消息已反映在價格後，新買家不一定還能多賺。** 預期報酬也不是保證報酬；以上數字是模型例子，不是實際股價預測。

### 4. EMH 與 AR(1)：一定先看變數是價格還是報酬【多次詢問】

**效率市場假說（efficient market hypothesis, EMH）**：價格反映相應資訊集合，不能只靠那些資訊持續取得風險調整後的超額報酬。

|形式|已反映的資訊|
|---|---|
|弱式（weak-form）|歷史價格、報酬、成交量|
|半強式（semi-strong）|全部公開資訊，包含歷史價格|
|強式（strong-form）|公開與非公開資訊|

**老師 Q1 問的是「價格的 AR(1)」：**

$$P_{t+1}=\mu+\rho(P_t-\mu)+\varepsilon_{t+1}$$

若 $\mu=100,\rho=0.5,P_t=120$，則條件預測為 110。再無新衝擊時依序為 105、102.5，價格往固定平均值回歸。這提供利用過去價格預測價格變動的規律，與老師簡化 EMH 模型中的不可預測新消息相衝突。

**後來為了延伸解釋，對話另談到「報酬的 AR(1)」：**

$$R_t=\alpha+\rho R_{t-1}+\varepsilon_t$$

- $\rho>0$：報酬有正自相關，前期較高報酬傾向接較高報酬。
- $\rho<0$：報酬有負自相關，傾向反轉。
- $\rho=0$：前一期報酬沒有這個模型中的線性預測作用。

> [!warning] 這是先前講解最容易造成混淆的地方
> 價格的簡單隨機漫步是 $P_{t+1}=P_t+\varepsilon_{t+1}$，**價格係數是 1**；相應變動量不具有前一期的可預測性。不能把「報酬模型的係數約為 0」直接搬去回答「價格模型的係數」問題。
> Q1 考試先按老師的價格模型回答。延伸討論時，統計可預測不必然等於可獲利，還要考慮風險補償與交易成本；係數為零也不代表已證明所有形式的市場效率。

**Q1 簡答記法：** 價格反映可用資訊。若價格按係數明顯小於 1 的 AR(1) 回歸固定平均，就能由過去價格預測變動；簡化 EMH 模型下這種獲利機會會被交易消除，剩下的價格變動來自無法預測的新消息。

### 5. 理性預期：整體平均沒錯，不等於每種情況都沒偏【曾明說不懂】

你曾問「條件平均為零」與「整體平均為零」的底層差異。

每天預測通勤 30 分鐘，但雨天平均 40、晴天平均 20。若雨晴各半，全部混在一起，誤差平均為零；但**既然出門前知道天氣，就已知道該怎麼修正預測**。因此原預測沒有用好已知資訊。

理性預期（rational expectations）要求：

$$X^e=E(X\mid\Omega),\qquad E[X-X^e\mid\Omega]=0$$

$\Omega$ 是預測時可用資訊。雨天改估 40、晴天改估 20，才消除這個可修正的平均偏差。

**不代表：** 每次都猜中、誤差一半正一半負、只有幾次預測的樣本平均必為零。例：$0.9(-1)+0.1(9)=0$，即使九成誤差為負，平均仍可為零。

**檢查句：** 我現在已知的資訊，能不能指出這個平均預測仍應上修或下修？能，就還沒有用完資訊。

## 二、你曾要求解釋的基礎觀念

### 6. 殖利率上升，為什麼價格下跌？【曾詢問】

到期殖利率（yield to maturity, YTM）是讓未來承諾付款現值等於今天價格的折現率。固定給付的一年期債券，明年拿 105：

$$P=\frac{105}{1+i},\qquad i=\frac{105}{P}-1$$

$P=100$ 時 $i=5\%$；若要求殖利率升到 10%，$P=105/1.1=95.45$。**未來領的錢沒變，買得便宜才能有更高殖利率。**

|容易混淆的量|定義|
|---|---|
|票面利率（coupon rate）|年票息／面額|
|當期殖利率（current yield）|年票息／現在價格|
|到期殖利率（YTM）|由全部承諾給付與價格解出的折現率|
|持有期間報酬率（holding-period return）|（期間現金收入＋賣價−買價）／買價|

升息造成舊債價格下跌，不代表舊債的固定票息突然增加。提前賣出時，實際報酬也不必等於原本買進時的 YTM。

### 7. 期限結構三理論與曲線判讀【曾要求詳細講解】

|理論|不同期限債券的關係|利率決定方式|
|---|---|---|
|預期理論（expectations theory）|完全替代|目前與預期未來短率的平均|
|市場區隔理論（segmented markets theory）|不替代|各期限各自的供需|
|流動性溢酬理論（liquidity premium theory）|不完全替代|平均短率＋期限溢酬（term premium）|

Q15：$(1+1.5+2+2.5+2.5)/5=1.9\%$；再加 0.4 個百分點溢酬，得到 2.3%。**五年平均要含今年。**

在課堂正期限溢酬的設定下：向上曲線不必代表預期升息；平坦曲線可能是預期短率下降抵銷溢酬；倒掛表示預期短率平均下降得足以壓過正溢酬。曲線橫軸是**到期期限**，不是未來日期；不能把每個點直接當成該年短率。

### 8. 銀行資本究竟包含什麼？提款從哪裡扣？【曾直接詢問】

$$\text{Assets}=\text{Liabilities}+\text{Bank capital}$$

|分類|例子|銀行的角度|
|---|---|---|
|資產（assets）|準備金、證券、貸款|銀行擁有、可收回的資源|
|負債（liabilities）|客戶存款、銀行借款|銀行欠別人的錢|
|資本／淨值／權益（capital／net worth／equity）|股東投入、保留盈餘等|資產減負債後的剩餘|

**資本不是一包現金，也不是「準備金＋證券＋貸款」。** 這幾項是資產；本課簡化資產負債表中的資本是權益。

Q23 的提款 $x$ 使準備金減 $x$、存款負債也減 $x$，在沒有額外損失的設定下，資本不變。準備金仍須滿足提款後存款的 10%：

$$80-x\ge0.1(500-x)\Rightarrow x\le\frac{30}{0.9}=33.33$$

**超額準備為 30，最大可承受流出卻是 33.33**，因為存款下降也讓法定準備要求下降。

### 9. 存續期間與到期年數不同【本次明確詢問】

存續期間（duration）是**以每筆收款現值占總價值的比例為權重，算出的平均收款時間**：

$$D=\sum_t t\frac{PV(CF_t)}{P}$$

三年後才一次付款，$D=3$；三年到期、期間先付正票息的債券，部分收款更早，$D<3$。若第 1、3 年收款分別占總現值的 20%、80%，則 $D=1(0.2)+3(0.8)=2.6$ 年。

對本題固定現金流，存續期間越長，價格對同樣利率變動越敏感。課堂公式使用：

$$\frac{\Delta P}{P}\approx-D\frac{\Delta i}{1+i}$$

若改用修正存續期間（modified duration）$D_{mod}=D/(1+i)$，才寫成 $\Delta P/P\approx-D_{mod}\Delta i$，不能兩種定義混用而重複除以 $1+i$。

**Q27：** $DGAP=3-0.9(2)=1.2$ 年；$\Delta NW\approx-100(1.2)(0.01)/1.1=-1.0909$ 百萬。這是資產的 −1.09%，卻是原淨值 10 的 −10.91%。

### 10. 逆選擇、道德風險與信用配給【曾詢問／看圖解題】

|概念|不知道什麼？|典型處理|
|---|---|---|
|逆選擇（adverse selection）|交易前，借款人的類型與風險|篩選（screening）|
|道德風險（moral hazard）|交易後，借款人是否採取合適行動|監督（monitoring）、限制條款、誘因設計|

Q28 的重點是留足成功報酬，讓借款人願意認真：

$$p_HR_b\ge p_LR_b+B\Rightarrow R_b\ge\frac{B}{p_H-p_L}=\frac{20}{0.4}=50$$

成功時可給銀行 $150-50=100$；**可抵押收入（pledgeable income）是期望值**，所以還要乘成功率：$0.9(100)=90$。自有財富至少 $100-90=10$。若只有 5，要借 95，但最多能可信承諾償還的期望值為 90，因此借不到；專案 NPV 為正也不保證能融資。

Q29 是辨認類型的問題：可辨識好人時，$0.8R_\ell=100\Rightarrow R_\ell=125$；好壞各半且不可辨識時，平均成功率 $m=0.5$，故 $R_\ell=200$。銀行在好人身上的期望利潤為 $0.8(200)-100=60$，壞人為 $0.2(200)-100=-60$，整體損益兩平。這是交叉補貼（cross-subsidization）。

## 三、你提過老師會考的折現與精算補充

**每題先做：畫時間線 → 統一付款與利率週期 → 選共同評價日 → 列現值等式。**

|補充題型|必抓步驟|核對答案|
|---|---|---|
|65,000 貸款，180 月，付完第 12 期後名目年利率由 8% 降至 6%，皆按月複利|原月付金 → 按原利率算剩餘 168 期本金 → 按新利率算新月付金|原月付約 621.17；餘額 62,661.40；新月付 **552.19**|

**三個不能混淆：**

- 名目年利率 6%、按月複利，月利率為 $0.06/12$；若是有效年利率 6%，月利率為 $(1.06)^{1/12}-1$。
- 年金現值公式的落點是**首筆付款前一期**；Q12 首筆在第 4 年，$C/i$ 落在第 3 年，再折回今天 3 期。
- 本金餘額不能用「原借款−已繳全部款項」，因為已繳款項包含利息。有限期成長付款即使 $g>i$ 仍可逐筆折現；不要把 Gordon 永續模型的收斂限制搬過來。

## 四、考場最後一分鐘提醒【補充檢查，不等於你的錯題紀錄】

- **Q7 最佳回應（best response）≠均衡：** 必須兩人的實際選擇同時等於各自最佳回應。$s_1=1+0.25s_2,s_2=1+0.25s_1$ 解得各 $4/3$，這是努力，不是利潤。
- **Q25(a)/(b) 是不同銀行：** (a) $RWA=260$、最低資本 18.2、剩餘 3.8；(b) 另給閒置資本 2.1，可支持 30 的新增 RWA。房地美／房利美 150 或商業貸款 30 是替代方案。
- **Q26 與 Q27 問的東西不同：** Q26 算一年利潤，$(45-60)(0.015)=-0.225$ 百萬；Q27 算淨值市值，須用存續期間缺口。
- **百分點先化小數：** 10%→11% 是 $\Delta i=0.01$；1.5 個百分點是 0.015。
- **Q30 一人提款要清算多少本金？** $100/0.5=200$，所以等待者拿 0。不能把回收率 50% 誤解成每個人都能領 50。
- **納許均衡（Nash equilibrium）看單方面偏離：** Q30 的（等，等）、（提，提）都是均衡；均衡不代表集體最好，也不必只有一個。
