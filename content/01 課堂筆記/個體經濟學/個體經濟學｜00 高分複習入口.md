## 考場解法｜每一步都有目的

**先選最短且適用的路徑，再寫足能拿分的步驟。**「有效率」不是省略理由，而是同一關係只推一次、後續情境直接代入；題目指定 Lagrangian、微分或畫圖時，仍完成指定要求。

| 題型 | 優先方法 | 每一步要達成什麼 |
|---|---|---|
| 固定比例／Leontief | 加權項相等 → 代預算 | 先找不浪費的配比，再找買得起的數量 |
| Cobb–Douglas／基本消費 | 扣基本支出 → 按指數分配 → 除單價 | 先找可配置的錢，再把金額換成數量 |
| 平滑內點需求 | MU比＝價格比 → 代預算 | 先消去一個未知數，再求數量；同一公式可重複代入 |
| Slutsky | 舊、補償、新三情境表 | 分開相對價格與購買力，最後以兩段相加驗算 |
| 跨期選工作 | 比所得現值 | 同利率、同借貸機會與偏好下，先判斷哪份工作可買到更多；有問消費才續算 |
| 風險 | 期望財富 → 期望效用 → CE → 貼水 | 區分平均金額、平均效用、等值金額與風險成本 |
| CV／EV | 指定價格＋目標效用 → 最低支出 | 先確定比較基準，再把福利換成金額 |
| 生產 | 固定比例／單一投入／全部投入，先分類 | 分清要用配比、MP還是規模報酬，避免算錯問題 |

讀解答時，每一步都確認：**我在做什麼？為了得到哪個下一步需要的量？** 先完成「考場優先解法」，需要理解來源再讀較完整推導。純判斷題若只需指出定義或缺少條件，就不加無用計算。

### 容易犯錯的陷阱
**正確做法：** 先能說出下一步要對誰運算，再遮住答案動手做。

**錯法：** 看過解答就往下讀，會誤以為自己會寫。務必至少一次不展開詳解、用英文寫完整理由。
### 老師出題想考驗的概念
把同一原理搬到新數字、新政策或新情境；真正要記的是條件與解題順序。
### 如何更好地理解這個 concept
每做完一題，用一句中文說原因，再寫一至三句英文；答案不同時先查假設與比較基準。

## 英文作答｜重要名詞與得分句一起練

[[個體經濟學｜英文名詞與作答句型]]：六類雙語詞彙與18組英文作答範本。各概念筆記開頭也有本節中英名詞，考古詳解下附對應英文句子。

**每題固定順序：**

1. **State the condition.** 寫預算、固定比例或最適條件。
2. **Show the calculation.** 先說運算對象與固定條件，再顯示必要代入。例如：對 $U$ 的 $x_1$ 偏微分，固定 $x_2$，得到 $MU_1$。
3. **Explain the result.** 用英文說結果的原因，補上適用條件。

### 容易犯錯的陷阱
**正確做法：** 先寫條件、再列必要運算，最後用英文說理由；數量與福利分開比較。

**錯法：** 只寫True／False或數字；或把「消費增加」寫成「福利增加」。
### 老師出題想考驗的概念
英文只是表達工具；理由、算式與條件才構成可評分的答案。
### 如何更好地理解這個 concept
不要逐字翻譯長段中文；先用 because、therefore、provided that 組成短句。
