## 第 3 頁

C H A P T E R 0 1 ‧ 基礎介紹
CPU 是什麼？
中央處理器（Central Processing Unit）是電子裝置的運算核⼼，它負責讀取程式
指令、進⾏計算、控制資料流動，並協調記憶體、儲存裝置、顯示卡等元件⼯
作，被稱為電腦的「⼤腦」。相較於擅⻑平⾏運算的 GPU，CPU 具備優異的單執
⾏緒效能與彈性，適合處理序列性、決策性的通⽤運算任務。
01 ‧ CPU 是什麼與應用領域
三大核⼼組成：控制單元（CU）、算術邏輯單元（ALU）、暫存器（Registers）
指令週期：Fetch（擷取）→ Decode（解碼）→ Execute（執行）→ Writeback
（寫回）
關鍵性能指標：核心數／執行緒數、時脈頻率、快取容量、IPC（每週期指令
數）、每瓦效能
單核心效能 ≈ 時脈 × IPC
現代 CPU 多整合記憶體控制器、I/O、甚至 NPU∕GPU，⾛向 SoC 化設計

## 第 4 頁

C H A P T E R 0 1 ‧ 基礎介紹
CPU 是什麼？
核心數 Core:  一個CPU通常有很多核心，以AMD Venice CPU為例，其擁有256
核。每個核心都擁有獨立的Register、ALU、FPU/Vector Unit／SIMD、CU、
Load／Store Unit 
控制單元  CU: 負責「看懂程式要CPU做什麼」，包括取得下一條指令、解讀
指令內容、判斷需要哪個運算單元、指揮暫存器、ALU、FPU和快取工作
暫存器 Register:  是 CPU 核心裡最快的儲存空間，CPU進行運算時，通常不會
直接拿RAM裡的資料來計算，而是先把資料搬到暫存器。暫存器和L1快取的
差別是暫存器由指令直接指定使用，⽽L1快取由硬體⾃動管理\
整數與邏輯運算單元  ALU:  負責算數、比大⼩、邏輯判斷(AND、OR)
浮點運算單元 FPU: ALU主要擅長整數，FPU則擅長浮點數。現代CPU中，FPU
通常也會和向量運算能力結合
Load／Store Unit: 負責資料搬運，CPU的運算單元只能對暫存器裡的資料進
行計算，因此資料必須先從快取或RAM搬進暫存器。Load是「讀取」從記憶
體讀取到暫存器；Store是「寫入」將計算結果寫入RAM或快取
快取 Cache: L1到L3，速度從快到慢，容量從大到⼩，距離核⼼從近到遠
記憶體控制器 IMC:  負責與RAM溝通。通常會在CPU規格中以多少通道DDR5
提及。
PCle: 可以理解成 CPU 對外連接設備的高速道路，伺服器 CPU通常提供很多
PCIe 通道，因為伺服器可能同時安裝多張GPU

C H A P T E R 0 5 ‧ 技術發展與趨勢
技術趨勢
05 ‧ 技術發展與趨勢
Chiplet 成為主流架構
製造單一大型晶片的難度隨著製造工藝要求越來越精細逐漸上升，對良率、產量
皆不利。chiplet可以把大型CPU拆解成多個部分分開製造，不同部分可使用不同
精度的製程，達成異質製程整合。台積電、日月光等封測廠必然受惠，欣興、南
電等載板廠則受惠於chiplet架構中載板尺寸變⼤
重點從單晶片效能轉向「每瓦效能」
重點公式: 總運算能力=單顆效能×可部署顆數×利用率
可部署顆數會受到總電力與散熱能力限制。
且大型雲端業者需要自建電廠，對於他們而言電力等同於戰略資源，越高的每瓦
效能代表越高的性價比
先進製程進入 2 奈米世代
TSMC N2 的核心變化是從 FinFET 轉向 nanosheet GAA ，能有效在同效能下降低功
耗，更有利閘極控制電流方向，降低漏電
AMD  第六代 EPYC Venice 已開始使用台積電 2nm 製程進⾏⽣產爬坡
