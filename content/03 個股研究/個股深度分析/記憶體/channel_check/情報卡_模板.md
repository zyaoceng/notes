# 情報卡模板（公開資訊與人脈訊息共用）

複製以下區塊、填完 append 進 intel_log.md。口述給 Claude 也可以，會代填成卡。

```
── 情報卡 #NNN ──────────────────────────
日期：YYYY-MM-DD
來源層級：官方 / 官方（匿名）/ 外媒 / 傳聞 / 一手人脈
取得管道：〔公開連結，或「某供應鏈友人口述」等——人脈卡務必寫管道性質〕
內容（一句話）：
可交叉驗證點：〔用什麼公開數據能證實或推翻它、何時〕
半衰期：〔這條資訊到哪一天就過期／被官方數字取代〕
映射：〔模型參數哪一格 or 哪張賭注卡——寫不出來＝噪音，不入卡〕
合法性自檢：〔重大性 × 非公開性。同時成立＝MNPI，不用、不記、不傳；
              產業拼圖（客戶下單節奏、缺貨體感、交期）＝合法馬賽克，可用〕
處置：已入模型 / 待驗 / 丟棄
─────────────────────────────────────────
```

三條紀律：
1. **映射欄是門檻**——連不到任何參數或賭注的訊息，再精彩都不入卡。
2. **人脈卡的可信度不因來源親近而加分**——一樣要有交叉驗證點，驗過才升級。
3. **合法性自檢欄是護身符**——寫下來的那一刻就是在保護你自己。
