# 個股研究總表

只抓屬性 `type: 個股研究` 的筆記；用「範本/個股研究」建的新筆記會自動出現在這裡。

## 我研究過哪些公司？
```dataview
TABLE ticker AS 代號, status AS 狀態, thesis AS 核心論點, target_price AS 目標價, updated AS 更新日
WHERE type = "個股研究"
SORT updated DESC
```

## 哪些研究超過 30 天沒更新？
```dataview
TABLE ticker AS 代號, status AS 狀態, updated AS 更新日
WHERE type = "個股研究" AND updated AND date(today) - updated > dur(30 days)
SORT updated ASC
```

## 哪些持股還沒寫出場條件？
```dataview
LIST ticker
WHERE type = "個股研究" AND status = "持有" AND !exit_condition
```
